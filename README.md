## The line

> Sorry, I panicked at the climax — even routers get performance anxiety.

A home Wi-Fi router excuses itself for dropping the connection at the exact
moment a movie reaches its climax. The joke turns on the double meaning of
"performance": the router isn't broken, it's nervous — it panicked at the
climax just like the viewer did. Short, self-contained, and a fresh angle
rather than the usual buffering gag.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (UTF-8, 71 characters).
Python 3 standard library only, no network access.
